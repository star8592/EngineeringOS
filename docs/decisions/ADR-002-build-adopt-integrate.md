# ADR-002: Build / Adopt / Integrate
Status: Accepted

Do not rebuild mature deterministic infrastructure without evidence. Git/GitHub owns source history and merge mechanics; CI owns repeatable checks; coding agents own implementation; DevControl owns authorized machine execution for this project; durable workflow technology may own long-running state only when experiments justify it.

EngineeringOS initially owns the missing semantic layer: intent normalization, Engineering World Model, architecture governance, semantic conflict detection, continuous convergence, and lifecycle closure.
