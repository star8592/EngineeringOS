# ADR-004: Durable engineering memory is part of Definition of Done
Status: Accepted

Important project discussions must converge into version-controlled durable state. Conversations are not authoritative project memory.

Material work is not complete until relevant canonical documents, ADRs, experiment findings, schemas/models, and evidence references are reconciled with the new state. Existing canonical documents should be updated rather than accumulating contradictory chat-derived notes.
