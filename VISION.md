# Vision

AI has made code generation cheap. The bottleneck is shifting to coordination, correctness, architectural continuity, verification, and convergence.

## Mission
Maintain a durable Engineering World Model linking intent, decisions, tasks, agents, conversations, code, tests, evidence, releases, production, incidents, and learning.

## Core hypotheses
1. Cross-conversation work can be normalized into one reliable Engineering Graph.
2. Semantic conflicts and architecture drift can be detected beyond textual Git conflicts.
3. Work can close the loop: Intent -> Task -> Implementation -> Evidence -> Integration -> Release -> Production Verification -> Cleanup -> Learning.

## First-phase non-goals
- Building another coding agent.
- Replacing Git/GitHub or CI/CD.
- Prematurely selecting Temporal, Dagger, OpenHands, or other infrastructure.
- Productization before the DevControl proving ground demonstrates value.
